# CampusConnect 🎓

CampusConnect is a full-stack Event Management Platform built for colleges. It allows students to discover and register for events while providing coordinators with tools to create events, manage registrations, and track attendance through QR code scanning.

---

## Features

### Student
- Register & Login
- Browse Events
- View Event Details
- Register for Events
- Payment Simulation
- QR Ticket Generation
- View My Registrations
- Attendance Status

### Event Coordinator
- Create Events
- Edit Events
- Delete Events
- Dashboard
- View Participants
- Search Participants
- QR Attendance Scanner
- Manual Attendance

### Admin
- Manage Events
- Dashboard
